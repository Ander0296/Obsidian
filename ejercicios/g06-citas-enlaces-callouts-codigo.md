# g06 — Citas, enlaces web, callouts y código (guiada)

No depende de otras notas: todo pasa en una nota nueva.
Si te trabás: Sesión #07 de GUIA.md · Checklist: ToDo/markdown.md
Si un comando no se llama exactamente así, contame qué ves.

1. **Nota nueva.** `Ctrl+N` → nombre `g06 sintaxis`. Todo lo que sigue va
   en esa nota, cada bloque separado del anterior por una línea en blanco.

2. **Dos citas.** Tipeá:
   ```
   > El café se toma sin apuro.

   > Y el agua nunca hirviendo.
   ```
   ✔ Dos citas separadas, cada una con su barra a la izquierda.

3. **Enlace web.** Tipeá:
   ```
   [Ayuda de Obsidian](https://help.obsidian.md)
   ```
   ✔ Al sacar el cursor de esa línea se lee solo "Ayuda de Obsidian", como enlace.

4. **Callout.** Tipeá:
   ```
   > [!tip] Dato
   > La molienda fina es para el espreso.
   ```
   ✔ Un recuadro de color con un ícono y el título "Dato".

5. **Bloque de código.** Tipeá lo de adentro (las líneas `~~~` son solo
   el marco del ejemplo: no se tipean):
   ~~~
   ```python
   print("café")
   ```
   ~~~
   ✔ Un recuadro con letra de máquina y el código en colores.

6. **Vista de lectura.** `Esc` y `Ctrl+E`. Probá escribir algo. Otra vez
   `Ctrl+E`. Si no cambia la vista, usá el botón del libro (arriba a la
   derecha) y contámelo.
   ✔ En lectura no se ve ningún símbolo ni se puede escribir.

**Desafío:** en la misma nota, sin mirar los pasos: una cita con
`Primero el agua, después el café.`; un enlace que diga `Platzi` y lleve
a `https://platzi.com`; un callout de tipo `warning` con título `Ojo` y
texto `No usar agua hirviendo.`; y un bloque de código `html` con `<p>Hola</p>`.
