# g02 — Markdown básico (guiada)

Nota: `Cafetería Italiana` (ya la tenés: borrá todo su contenido y empezá de cero).
Tipeá cada bloque TAL CUAL, desde el principio de la línea, sin agregar
paréntesis ni nada. Después de cada paso, mirá con `Ctrl+E` y volvé.
Si te trabás: Sesiones #02-#03 de GUIA.md · Checklist: ToDo/markdown.md

1. **Títulos** (`#` + espacio = título 1; `##` + espacio = título 2)
   ```
   # Cafetería Italiana
   ## Cómo funciona
   ```
   ✔ Dos títulos de distinto tamaño.

2. **Énfasis**
   ```
   El agua sube por *presión* y sale **muy caliente**: ==cuidado==.
   ```
   ✔ Cursiva, negrita y resaltado en la misma línea.

3. **Lista numerada** (número + punto + espacio + texto)
   ```
   ## Pasos
   1. Llenar el depósito con agua
   2. Poner el café molido
   3. Calentar a fuego bajo
   ```
   ✔ Una lista numerada.

4. **Sublista.** Debajo del paso 3 tipeá `- Sin apretar el café`, `Esc`, y `>>`.
   ✔ Queda corrida como subnivel. `<<` la devuelve.

5. **Tareas** (guion + espacio + corchetes con un espacio adentro + espacio + TEXTO)
   ```
   ## Para comprar
   - [ ] Café molido
   - [ ] Filtros
   ```
   ✔ Dos casillas. En modo normal: cursor en "Filtros", `ddkP` la sube;
   y para tildar una: `f[` `l` `rx`.

6. **Separador y etiqueta.** Fijate que hay una línea VACÍA antes del `---`.
   ```
   Fin de la nota

   ---
   #café
   ```
   ✔ Una raya y la etiqueta como píldora. Ahora borrá la línea vacía:
   "Fin de la nota" se vuelve título. Volvé a poner la línea vacía.

7. **`Ctrl+E` según el modo.** Probalo en modo normal y en modo insertar.
   Anotá si en los dos cambia a lectura.

**Desafío:** nota `Prensa francesa` con un título, una lista numerada de
3 pasos, una tarea tildada y un enlace a `[[Café]]`. El texto, cualquiera.
