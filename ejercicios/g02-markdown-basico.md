# g02 — Markdown básico (guiada)

En tu nota `Cafetería Italiana`, borrá todo y tipeá este bloque TAL CUAL
(dejá las líneas vacías donde están):

```
## Pasos
1. Llenar el depósito con agua
2. Poner el café molido

## Para comprar
- [ ] Café molido
- [ ] Filtros

Fin de la nota

---
#café
```

1. `Ctrl+E` → ✔ lista numerada, dos casillas, una raya y la etiqueta. `Ctrl+E` para volver.
2. Modo normal, cursor en "Café molido" (la tarea), `ddp` → ✔ baja un lugar.
3. Tildá una tarea: `f[` `l` `rx` → ✔ queda marcada.
4. Borrá la línea vacía de arriba del `---` → ✔ "Fin de la nota" se vuelve título. Volvé a ponerla.
