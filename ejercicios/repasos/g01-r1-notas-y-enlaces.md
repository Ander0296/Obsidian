# Repaso r1 de g01 — Notas y enlaces (desde cero)

Sin mirar g01 ni tus notas viejas. Solo con el teclado, en Cerebro.
Tema de relleno: té. Las notas son NUEVAS y el texto a tipear está abajo.
Si te trabás: Sesión #01 de GUIA.md (anotá en qué fue, y seguí).

Objetivos:

- Crear la nota `Té`.
- Escribir en `Té` la frase 1: su enlace apunta a una nota que todavía no existe.
- Crear `Infusión` desde ese enlace.
- Escribir en `Infusión` la frase 2, eligiendo el enlace de la lista.
- Volver a `Té` sin mouse y seguir su enlace desde el modo normal de Vim.
- Crear `Tetera` con la frase 3 y sumarle a `Infusión` la frase 4.
- Ver los enlaces entrantes de `Té`: tienen que ser dos notas.
- Saltar a `Infusión` por su nombre.
- Agregarle la frase 5 a `Té` desde Neovim y verla aparecer en Obsidian.
- Mirar `Té` en vista de lectura y volver a edición.

Frase 1:
```
El té se prepara por [[Infusión]].
```

Frase 2:
```

```

Frase 3:
```
Sirve para preparar el [[Té]] sin que se enfríe.
```

Frase 4:
```
Se hace dentro de una [[Tetera]].
```

Frase 5:
```
Línea agregada desde Neovim.
```
