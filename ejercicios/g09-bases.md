# g09 — Bases (guiada)

No depende de otras notas: todo se crea acá.
Si te trabás: Sesión #10 de GUIA.md (propiedades: Sesión #08)
Si un comando o un botón no se llama exactamente así, contame qué ves.

1. **Dos notas con propiedades.** `Ctrl+N` → nombre `g09 Huila`. En la primera
   línea (`i`) tipeá `---` y cargá en el panel:
   ```
   tipo: grano
   tueste: claro
   ```
   Repetí con otra nota, `g09 Nariño`:
   ```
   tipo: grano
   tueste: oscuro
   ```
   ✔ Cada nota muestra arriba sus dos propiedades.

2. **Crear la base.** `Ctrl+P` → escribí `base` y elegí el comando que crea
   una base nueva. Renombrala `g09 granos` (probá `F2`).
   ✔ Una tabla con TODAS las notas de la bóveda, mezcladas.

3. **Filtrar.** Botón Filtrar → añadir filtro → propiedad `tipo`, condición
   `es`, valor `grano`.
   ✔ Quedan solo `g09 Huila` y `g09 Nariño`.

4. **Columnas.** Botón Propiedades → activá `tipo` y `tueste`.
   ✔ Dos columnas nuevas, cada fila con sus valores.

5. **Editar desde la base.** En la fila de `g09 Nariño`, cambiá `oscuro` por
   `medio` en la celda. Después `Ctrl+O` → `g09 Nariño`.
   ✔ En la nota, `tueste` dice `medio`: la base editó la nota.

6. **Una nota nueva entra sola.** `Ctrl+N` → nombre `g09 Tolima`, con:
   ```
   tipo: grano
   tueste: claro
   ```
   Después `Ctrl+O` → `g09 granos`.
   ✔ `g09 Tolima` ya está en la tabla, sin haber tocado la base.

**Desafío:** sin mirar los pasos: creá otra base, `g09 claros`, que muestre
solo los granos de tueste claro, con la columna `tueste` a la vista. Si te
quedan dos notas, vas bien.
