# g04 — Carpetas, PARA y bandeja (guiada)

Usa las notas del café. Si te trabás: Sesión #05 de GUIA.md
Si un ajuste no se llama exactamente así, contame qué ves.

1. **Cinco carpetas.** En el explorador, ícono de carpeta nueva (arriba).
   Creá: `00 Bandeja`, `01 Proyectos`, `02 Áreas`, `03 Recursos`, `04 Archivo`.
   ✔ Quedan en ese orden por los números.

2. **La bandeja como destino.** `Ctrl+,` → Archivos y enlaces → ubicación
   por defecto para notas nuevas → en la carpeta especificada → `00 Bandeja`.

3. **Capturar.** `Ctrl+N` → nota `Comprar granos` con este texto:
   ```
   Pedir granos para el [[Café]]
   ```
   ✔ La nota aparece DENTRO de `00 Bandeja` sola.

4. **Mover.** Abrí Café → `Ctrl+P` → escribí `mover` → mover archivo a
   otra carpeta → `03 Recursos`. Igual con Molienda, Espreso, Cafetería
   Italiana y Prensa francesa.
   ✔ Las cinco en `03 Recursos`.

5. **Mover no rompe enlaces.** Abrí Molienda, `Esc`, `f[`, `Alt+Enter`.
   ✔ Abre Café igual: Obsidian enlaza por NOMBRE, no por carpeta.

6. **Procesar la bandeja.** Mové Comprar granos a `01 Proyectos` (tiene
   un fin: cuando comprás, terminó).
   ✔ `00 Bandeja` queda vacía.

**Desafío:** `Ctrl+N` una nota cualquiera, comprobá que cae en la
bandeja, y movela a `04 Archivo`. Borrá la nota "Sin título" que te quedó suelta.
